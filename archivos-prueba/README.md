# Programas de prueba de miniC

Ejemplos de entrada.

| Archivo | Enfoque del caso |
|---|---|
| `prueba.mc` | Ejemplo general |
| `prueba_declaraciones.mc` | Declaración de identificadores |
| `prueba_errores.mc` | Casos destinados a provocar diagnósticos |
| `prueba_exp_ternarias.mc` | Expresiones ternarias |
| `prueba_if_else.mc` | Estructuras condicionales |
| `prueba_read.mc` | Operaciones de lectura |
| `prueba_vacio.mc` | Entrada vacía |
| `prueba_profe.mc` | Caso de referencia de la práctica |

Desde la raíz del repositorio:

```bash
make
./miniC archivos-prueba/prueba_if_else.mc
```
